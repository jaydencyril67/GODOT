# DigitalWorld HQ — Godot Prototype

A lightweight, procedural 3D headquarters prototype for Godot 4, designed to run on mobile. The scene is built from simple meshes and materials, so no external assets are required.

## Open on Android
1. Download this repository as a ZIP from GitHub, or clone it with your preferred Git client.
2. Extract it and open `project.godot` in Godot Android Editor.
3. Import the project, then press Play.

## Prototype layout
- Daylit modern headquarters with glass and pale-concrete facade
- Reception area with desk and waiting sofa
- Boardroom with meeting table and chairs
- Simple plants and room labels

This is an initial visual prototype, not a finished game. The next step is to refine materials, scale, room navigation, and mobile performance based on the preview.
