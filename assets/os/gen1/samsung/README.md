# Gen 1 Samsung TouchWiz Nature UX assets

Place the five authentic Samsung Galaxy S III / Android 4.x reference screenshots in this folder.

Use these exact filenames:

- `lock_screen.png` — TouchWiz swipe-to-unlock lock screen
- `home_screen.png` — TouchWiz Nature UX home screen
- `app_drawer.png` — horizontally paginated application drawer
- `notification_panel.png` — expanded notification shade and quick toggles
- `recent_apps.png` — Android recent-apps / task switcher

## Upload notes

- Prefer original, uncropped PNG screenshots.
- Keep the full phone display visible; do not include browser controls or article captions.
- Do not rename the files: the simulator integration will use these paths.
- These are visual reference layers. Godot will provide the interactive touch handling and navigation.
