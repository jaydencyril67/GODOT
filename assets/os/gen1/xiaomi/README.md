# Xiaomi MIUI — Generation 1

This folder is reserved for the Generation 1 Xiaomi MIUI reference screens (Android 4.0-era MIUI).

Upload these six JPG files here to enable screenshot-backed previews:

- `lockscreen.jpg`
- `homescreen.jpg`
- `appsdrawer.jpg`
- `controlcenter.jpg`
- `notification.jpg`
- `recentapps.jpg`

Until the references are uploaded, the OS preview displays an explicit MIUI reference-pending screen. This family remains separate from Samsung TouchWiz and Google Stock Android.
