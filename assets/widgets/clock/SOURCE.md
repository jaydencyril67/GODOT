# Analog Clock Asset Pack

Imported original assets from **2D Analog Clock Assets (CC0, Vector)** by coco-acc.

Source: https://coco-acc.itch.io/2d-analog-clock-asset
License: CC0 1.0 Universal (as stated by the source asset page).

Contents:
- 18 original clock faces in 256, 512, and 1024 pixel variants.
- Original hour, minute, and second hand PNGs for all 18 matching designs.
- Original Vector.svg source file.

This is an asset-only import. No Godot scenes, scripts, widget behavior, or rendering implementation are included.
