# Charging-port research images

Place the five downloaded image files in this folder using these exact names. The phone research screen loads only the image for the next upgrade.

| Required filename | Suggested real-world photo | Source and licence |
|---|---|---|
| `dc_barrel_jack.jpg` | DC barrel power jack/socket | [SparkFun DC Barrel Power Jack Connector (SMD)](https://commons.wikimedia.org/wiki/File:DC_Barrel_Power_Jack_Connector_(SMD)_(12311783276).jpg) — SparkFun Electronics, CC BY 2.0 |
| `mini_usb_mini_b.jpg` | Mini-B receptacle on a camera (crop around the Mini-B port if desired) | [HDMI and USB Mini B receptacles.jpg](https://commons.wikimedia.org/wiki/File:HDMI_and_USB_Mini_B_receptacles.jpg) — Swift.Hg, CC BY-SA 3.0 |
| `micro_usb_micro_b.jpg` | Micro-USB plug | [MicroB USB Plug.jpg](https://commons.wikimedia.org/wiki/File:MicroB_USB_Plug.jpg) — Music Sorter, CC BY-SA 3.0 |
| `apple_lightning.jpg` | Lightning socket on an iPhone | [Apple Lightning Connector.jpg](https://commons.wikimedia.org/wiki/File:Apple_Lightning_Connector.jpg) — Phiarc, CC BY-SA 4.0 |
| `usb_type_c.jpg` | USB-C receptacle on a laptop | [USB-C connector on a laptop.jpg](https://commons.wikimedia.org/wiki/File:USB-C_connector_on_a_laptop.jpg) — Logant547, CC BY 4.0 |

Download the **Original file** from each Commons page, rename it to the matching filename above, and keep the attribution and licence terms with the project. If an image is cropped or edited, note that modification in the attribution record.

The game code expects these files at:
`res://assets/research/charging_ports/`
