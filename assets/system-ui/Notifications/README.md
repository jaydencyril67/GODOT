# Notifications Assets

Source repository: https://github.com/fauyds/QuickSettings
License: MIT (see SOURCE-LICENSE)

## Contents
- Icons: 31 notification action icons.
- Category-Icons: 20 notification category icons.
- Backgrounds: 3 notification backgrounds.
- Layouts: 4 notification list, card, category header, and footer layouts.

## Compatibility
These are original Android XML resources. They have been extracted and organized, but have not been converted to Godot-compatible assets or integrated into the game.

The source repository's application code, build files, signing keys, and unrelated resources are not included.
