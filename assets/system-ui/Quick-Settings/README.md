# Quick Settings Assets

Source repository: https://github.com/fauyds/QuickSettings
License: MIT (see SOURCE-LICENSE)

## Contents
- Icons: 37 Quick Settings vector drawable XML files.
- Shapes: 11 tile shape XML resources.
- Layouts: compact panel, expanded panel, and tile item layouts.

## Compatibility
These are original Android XML resources. They have been extracted and organized, but have not been converted to Godot-compatible assets or integrated into the game.

The source repository's application code, build files, signing keys, and unrelated notification UI resources are not included.
