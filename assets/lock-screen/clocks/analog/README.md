# DigitalWorld Lock-screen Analog Clock Artwork

Upload the finished transparent analog clock image files into this folder.

## Upload guidelines
- Keep the original transparent PNG files; do not flatten them onto a background.
- Use clear, unique filenames, for example `analog-clock-01.png`, `analog-clock-02.png`, and so on.
- Do not upload generated previews, screenshots, or duplicate files.
- Keep each clock image at its original resolution.

These are complete clock artwork assets. The lock-screen implementation will be updated only after the uploaded images have been inspected and their design/hand behavior has been confirmed.
