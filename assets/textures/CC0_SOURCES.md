# PBR texture provenance

The following image maps are CC0 1.0 assets from Poly Haven. The texture maps are included locally so the Godot project does not depend on external downloads at runtime.

## Concrete Wall 004
Source: https://polyhaven.com/a/concrete_wall_004
License: CC0 1.0 Universal (public domain dedication; attribution is not required).
Maps: concrete wall albedo/diffuse, OpenGL normal, roughness, ambient occlusion.
Original source copies were obtained from the Godot RL Agents examples repository, which uses the Poly Haven maps:
https://github.com/edbeeching/godot_rl_agents_examples/tree/main/examples/FlyBy

## Concrete Floor
Source: https://polyhaven.com/a/concrete_floor
License: CC0 1.0 Universal (public domain dedication; attribution is not required).
Maps: concrete floor diffuse/albedo, OpenGL normal, roughness.
Original source copies were obtained from:
https://github.com/AetherRadar/operation-steel-tide/tree/main/assets/textures

## Brown Planks 09
Source: https://polyhaven.com/a/brown_planks_09
License: CC0 1.0 Universal (public domain dedication; attribution is not required).
Maps: diffuse/albedo, OpenGL normal, packed ARM map (red = ambient occlusion, green = roughness, blue = metallic).
Original source copies were obtained from:
https://github.com/jana-cuch/HauntedHouse-R3F/tree/main/public/window/brown_planks_09_1k

These surface maps are reused under their original CC0 terms. The game's own source code and other assets keep their existing terms.
